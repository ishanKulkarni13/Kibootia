> **Implementation:** this document is the reference for implementation status. The rows were first written from a snapshot of 2026-10-27 and updated on 2026-11-08 after milestone 0 was implemented.

The one place that compares what is intended with what exists. Values follow the [vocabulary](../../meta/living-documentation.md): planned, observed, verified. The [technology catalogue](../../technology/README.md) lists what is selected and links here for status.

**Milestone 0 is verified.** Its 13 tests and the secret scan passed in CI on Eclipse Temurin 25 on pull request #2 (run 42477195261, 2026-11-08) and again on `main` after the merge (run 42477240084), as the [verification standard](../../engineering/testing/verification-standard.md) requires. Milestones 1 and 2 are built, and their CI jobs (backend, frontend, image scan, end-to-end sign-in, secret scan) passed on pull request #4 (run 42605511477, 2026-11-09). Milestone 3 is built and its CI jobs (backend, frontend, image scan, end-to-end, secret scan) passed on pull request #5 (run 42780048416, 2026-11-10). Rows that said "no CI run yet" were re-marked on 2026-11-24 against the CI record (jobs of runs 42589726681, 42605511477 and 42959703043); a row that still says so has no run to point to. Milestone 4 is built and its CI jobs (backend with 103 fast and 238 integration tests, frontend with 168 unit tests, image scan, 22 end-to-end tests, secret scan) passed on pull request #6 (run 42873216224, 2026-11-10). Milestone 5 is built and its CI jobs (backend, frontend, image build and scan, secret scan, and the four rows of the `module-removal` job) passed on pull request #7 (run 42959703043, 2026-11-11) and again on `main` after the merge (run 42981706613). Its 31 end-to-end tests were skipped in both of those runs and passed in CI for the first time on 2026-11-24 (run 45354022559, pull request #10), after the three defects they exposed were fixed; OQ-86 is closed. Milestone 6 is unbuilt. Branch `m-5-1` (2026-11-24) holds a security fix, declared module dependencies, repository files and an [architecture assessment](../../architecture/architecture-assessment.md); its full local backend run passed and its CI run is pending (table at the end). Authorization beyond milestone 3 is planned in the [authorization roadmap](authorization-roadmap.md); how far the code is from each requirement is in [traceability](../requirements/authorization/traceability.md). The container image scan passed for both images (run 42959703043, 2026-11-11), which finishes OQ-44.
